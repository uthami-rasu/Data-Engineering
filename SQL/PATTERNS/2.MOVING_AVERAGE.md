# 2. Moving Average

## Problem Statement

Given daily sales data, calculate the average sales of the **current day and previous 2 days**.

This is also called a **3-day Moving Average**.

---

## Input

**sales**

| sale_date  | amount |
| ---------- | -----: |
| 2024-01-01 |    100 |
| 2024-01-02 |    200 |
| 2024-01-03 |    300 |
| 2024-01-04 |    400 |
| 2024-01-05 |    500 |

---

## Expected Output

| sale_date  | amount | moving_avg |
| ---------- | -----: | ---------: |
| 2024-01-01 |    100 |     100.00 |
| 2024-01-02 |    200 |     150.00 |
| 2024-01-03 |    300 |     200.00 |
| 2024-01-04 |    400 |     300.00 |
| 2024-01-05 |    500 |     400.00 |

---

## How It Works

For each row, consider:

```text
Current Row
+
Previous 2 Rows
```

### Jan 1

```text
100
```

Average = 100

---

### Jan 2

```text
100, 200
```

Average = (100 + 200) / 2 = 150

---

### Jan 3

```text
100, 200, 300
```

Average = 200

---

### Jan 4

```text
200, 300, 400
```

Average = 300

---

### Jan 5

```text
300, 400, 500
```

Average = 400

---

## SQL Solution

```sql
SELECT
    sale_date,
    amount,
    AVG(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING
        AND CURRENT ROW
    ) AS moving_avg
FROM sales;
```

---

## Understanding the Window Frame

```sql
ROWS BETWEEN 2 PRECEDING
AND CURRENT ROW
```

Means:

```text
Take:
Current Row
+
2 rows before it
```

### Example for Jan 5

```text
Jan 03 = 300
Jan 04 = 400
Jan 05 = 500
```

Average:

```text
(300 + 400 + 500) / 3
= 400
```

## Running Total vs Moving Average

### Running Total

```sql
SUM(amount) OVER (
    ORDER BY sale_date
)
```

Result:

| Date  | Running Total |
| ----- | ------------: |
| Jan 1 |           100 |
| Jan 2 |           300 |
| Jan 3 |           600 |
| Jan 4 |          1000 |

Keeps growing.

---

### Moving Average

```sql
AVG(amount) OVER (
    ORDER BY sale_date
    ROWS BETWEEN 2 PRECEDING
    AND CURRENT ROW
)
```

Result:

| Date  | Moving Avg |
| ----- | ---------: |
| Jan 1 |        100 |
| Jan 2 |        150 |
| Jan 3 |        200 |
| Jan 4 |        300 |

Only looks at a fixed window.

## Key Recognition Pattern

When you hear:

- Average of last N days
- Rolling average
- Smoothed trend
- Average over recent records
- Moving window calculation

Think:

```sql
AVG(...) OVER (
    ORDER BY ...
    ROWS BETWEEN N PRECEDING
    AND CURRENT ROW
)
```

### Core Formula

```sql
AVG(column) OVER (
    ORDER BY some_column
    ROWS BETWEEN N PRECEDING
    AND CURRENT ROW
)
```

This is the classic **Moving Average** pattern.
