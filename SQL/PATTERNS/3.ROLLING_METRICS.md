# 3. Rolling Window Metrics

## Problem Statement

Given daily sales data, calculate the following for the **current day and previous 2 days**:

1. Rolling Sum
2. Rolling Count
3. Rolling Maximum
4. Rolling Minimum

---

## Input

**sales**

| sale_date  | amount |
| ---------- | -----: |
| 2024-01-01 |    100 |
| 2024-01-02 |    200 |
| 2024-01-03 |    300 |
| 2024-01-04 |    400 |
| 2024-01-05 |    500 |

---

## Expected Output

| sale_date  | amount | rolling_sum | rolling_count | rolling_max | rolling_min |
| ---------- | -----: | ----------: | ------------: | ----------: | ----------: |
| 2024-01-01 |    100 |         100 |             1 |         100 |         100 |
| 2024-01-02 |    200 |         300 |             2 |         200 |         100 |
| 2024-01-03 |    300 |         600 |             3 |         300 |         100 |
| 2024-01-04 |    400 |         900 |             3 |         400 |         200 |
| 2024-01-05 |    500 |        1200 |             3 |         500 |         300 |

---

# Understanding the Window

Window Definition:

```sql
ROWS BETWEEN 2 PRECEDING
AND CURRENT ROW
```

For Jan 05:

```text
300
400
500
```

These 3 rows form the active window.

---

## Rolling Sum

### Problem Statement

Find the sum of the current row and previous 2 rows.

### SQL

```sql
SELECT
    sale_date,
    amount,
    SUM(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING
        AND CURRENT ROW
    ) AS rolling_sum
FROM sales;
```

### Example

For Jan 05:

```text
300 + 400 + 500 = 1200
```

---

## Rolling Count

### Problem Statement

Count the rows in the current window.

### SQL

```sql
SELECT
    sale_date,
    COUNT(*) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING
        AND CURRENT ROW
    ) AS rolling_count
FROM sales;
```

### Example

For Jan 05:

```text
300
400
500
```

Count = 3

# Combined Query

```sql
SELECT
    sale_date,
    amount,

    SUM(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS rolling_sum,

    COUNT(*) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS rolling_count,

    MAX(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS rolling_max,

    MIN(amount) OVER (
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS rolling_min

FROM sales;
```

# Interview Recognition Pattern

When you hear:

- Last N rows
- Last N days
- Previous K records
- Rolling metric
- Sliding window analytics
- Windowed aggregate

Think:

```sql
<AGGREGATE>() OVER (
    ORDER BY ...
    ROWS BETWEEN N PRECEDING
    AND CURRENT ROW
)
```

Where aggregate can be:

```sql
SUM()
AVG()
COUNT()
MAX()
MIN()
```

## Key Difference

| Concept           | Window Size                               |
| ----------------- | ----------------------------------------- |
| Running Total     | Beginning → Current Row                   |
| Moving Average    | Fixed Window                              |
| Rolling Metrics   | Fixed Window                              |
| Consecutive Dates | Not a window; uses ROW_NUMBER/LAG pattern |
