# SQL Gaps & Islands - Core Templates

## Template 1: Find Consecutive Streaks (Islands)

### Problem Statement

Given a list of dates, find groups of consecutive dates and calculate the start date, end date, and streak length.

### Input

| login_date |
| ---------- |
| 2024-01-01 |
| 2024-01-02 |
| 2024-01-03 |
| 2024-01-05 |
| 2024-01-06 |

### Expected Output

| start_date | end_date   | streak_length |
| ---------- | ---------- | ------------: |
| 2024-01-01 | 2024-01-03 |             3 |
| 2024-01-05 | 2024-01-06 |             2 |

### Logic

Generate a row number and create a grouping key:

```text
date      rn      date - rn
--------------------------------
Jan01     1       0
Jan02     2       0
Jan03     3       0

Jan05     4       1
Jan06     5       1
```

Rows with the same `(date - row_number)` value belong to the same streak.

### SQL Template

```sql
WITH streaks AS (
    SELECT
        login_date,
        login_date -
        ROW_NUMBER() OVER(
            ORDER BY login_date
        ) * INTERVAL '1 day' AS grp
    FROM user_logins
)
SELECT
    MIN(login_date) AS start_date,
    MAX(login_date) AS end_date,
    COUNT(*) AS streak_length
FROM streaks
GROUP BY grp
ORDER BY start_date;
```

### When to Use

- Consecutive login days
- Consecutive purchases
- Attendance streaks
- Longest activity streak
- Gaps and Islands interview problems

## Template 2: Detect Gaps Between Rows

### Problem Statement

Find the number of days between the current row and the previous row.

### Input

| login_date |
| ---------- |
| 2024-01-01 |
| 2024-01-02 |
| 2024-01-05 |
| 2024-01-06 |

### Expected Output

| login_date | gap_days |
| ---------- | -------: |
| 2024-01-01 |     NULL |
| 2024-01-02 |        1 |
| 2024-01-05 |        3 |
| 2024-01-06 |        1 |

### Logic

Retrieve the previous date using `LAG()` and subtract.

```text
Current    Previous    Difference
----------------------------------
Jan01      NULL        NULL
Jan02      Jan01       1
Jan05      Jan02       3
Jan06      Jan05       1
```

A difference greater than 1 indicates missing dates.

### SQL Template

```sql
SELECT
    login_date,
    login_date -
    LAG(login_date) OVER(
        ORDER BY login_date
    ) AS gap_days
FROM user_logins;
```

### When to Use

- Missing dates
- Missing orders
- Missing attendance records
- Data quality checks
- Detect breaks in activity

## Template 3: Check Whether Rows Are Consecutive

### Problem Statement

Determine whether the current row is consecutive with the previous row.

### Input

| login_date |
| ---------- |
| 2024-01-01 |
| 2024-01-02 |
| 2024-01-05 |
| 2024-01-06 |

### Expected Output

| login_date | consecutive |
| ---------- | ----------- |
| 2024-01-01 | NO          |
| 2024-01-02 | YES         |
| 2024-01-05 | NO          |
| 2024-01-06 | YES         |

### Logic

Check whether:

```text
current_date = previous_date + 1 day
```

Examples:

```text
Jan02 = Jan01 + 1 day  -> YES
Jan05 = Jan02 + 1 day  -> NO
Jan06 = Jan05 + 1 day  -> YES
```

### SQL Template

```sql
SELECT
    login_date,
    CASE
        WHEN login_date =
             LAG(login_date) OVER(
                 ORDER BY login_date
             ) + INTERVAL '1 day'
        THEN 'YES'
        ELSE 'NO'
    END AS consecutive
FROM user_logins;
```

### When to Use

- Login streak validation
- Consecutive attendance
- Consecutive purchases
- Consecutive transactions
- Streak-related interview questions
