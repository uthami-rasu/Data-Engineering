# Pattern 7: Top N Per Group

One of the most common SQL interview patterns.

---

# Concept Overview

Find the top N records within each group.

Examples:

- Top 3 employees per department
- Top 5 products per category
- Latest 2 orders per customer
- Highest salary in each department

---

# Problem Statement

Find the top 2 highest-paid employees from each department.

---

# Input

## employees

| emp_id | emp_name | dept | salary |
| ------ | -------- | ---- | -----: |
| 1      | John     | IT   |  10000 |
| 2      | Mike     | IT   |   9000 |
| 3      | Alex     | IT   |   8000 |
| 4      | Sara     | HR   |   7000 |
| 5      | Emma     | HR   |   6000 |
| 6      | David    | HR   |   5000 |

---

# Expected Output

| emp_name | dept | salary |
| -------- | ---- | -----: |
| John     | IT   |  10000 |
| Mike     | IT   |   9000 |
| Sara     | HR   |   7000 |
| Emma     | HR   |   6000 |

---

# Core Idea

Rank rows inside each group.

```sql id="1"
PARTITION BY dept
```

means:

```text
IT Department
-------------
John
Mike
Alex

HR Department
-------------
Sara
Emma
David
```

Ranking restarts for every department.

---

# Template 1: Top N Per Group Using ROW_NUMBER()

## SQL

```sql
WITH ranked AS (
    SELECT
        *,
        ROW_NUMBER() OVER(
            PARTITION BY dept
            ORDER BY salary DESC
        ) AS rn
    FROM employees
)
SELECT *
FROM ranked
WHERE rn <= 2;
```

---

# Step-by-Step Execution

## IT Department

| emp  | salary |  rn |
| ---- | -----: | --: |
| John |  10000 |   1 |
| Mike |   9000 |   2 |
| Alex |   8000 |   3 |

Keep:

```text
rn <= 2
```

Result:

```text
John
Mike
```

## HR Department

| emp   | salary |  rn |
| ----- | -----: | --: |
| Sara  |   7000 |   1 |


# Template 2: Top N Per Group Using DENSE_RANK()

## Problem

Include ties.

Input:

| emp  | dept | salary |
| ---- | ---- | -----: |
| John | IT   |  10000 |
| Mike | IT   |   9000 |
| Alex | IT   |   9000 |
| Bob  | IT   |   8000 |

---

## SQL

```sql
WITH ranked AS (
    SELECT
        *,
        DENSE_RANK() OVER(
            PARTITION BY dept
            ORDER BY salary DESC
        ) AS rnk
    FROM employees
)
SELECT *
FROM ranked
WHERE rnk <= 2;
```

---

## Output

| emp  | salary | rnk |
| ---- | -----: | --: |
| John |  10000 |   1 |
| Mike |   9000 |   2 |
| Alex |   9000 |   2 |

Notice:

```text
Both Mike and Alex returned
because salary is tied.
```

---

# ROW_NUMBER vs DENSE_RANK

## ROW_NUMBER()

```text
10000 → 1
9000  → 2
9000  → 3
8000  → 4
```

Only one employee gets rank 2.

---

## DENSE_RANK()

```text
10000 → 1
9000  → 2
9000  → 2
8000  → 3
```

Both employees get rank 2.

# Template 3: Latest Order Per Customer

## Input

| customer_id | order_date |
| ----------- | ---------- |
| 1           | 2024-01-01 |
| 1           | 2024-01-10 |
| 1           | 2024-01-20 |
| 2           | 2024-01-05 |
| 2           | 2024-01-15 |

---

## SQL

```sql
WITH ranked AS (
    SELECT
        *,
        ROW_NUMBER() OVER(
            PARTITION BY customer_id
            ORDER BY order_date DESC
        ) AS rn
    FROM orders
)
SELECT *
FROM ranked
WHERE rn = 1;
```

---

## Output

| customer_id | order_date |
| ----------- | ---------- |
| 1           | 2024-01-20 |
| 2           | 2024-01-15 |

# Common Mistakes

### Mistake 1

```sql
ROW_NUMBER() OVER(
    ORDER BY salary DESC
)
```

Missing:

```sql
PARTITION BY dept
```

This ranks the entire table, not each department.

---

### Mistake 2

Using:

```sql
ROW_NUMBER()
```

when ties should be included.

Use:

```sql
DENSE_RANK()
```

instead.

---

# Recognition Guide

When you hear:

- Top N per department
- Latest order per customer
- Highest salary per team
- Best product per category
- Most recent record per user

Think:

```sql
ROW_NUMBER()
OVER(
    PARTITION BY group_column
    ORDER BY metric DESC
)
```

## Summary

The formula you'll use repeatedly is:

```sql
ROW_NUMBER() OVER(
    PARTITION BY group_column
    ORDER BY sort_column DESC
)
```

This single pattern powers:

- Top N Per Group
- Deduplication
- Latest Record Per User
- First Record Per User
- Highest Salary Per Department

Which is why **Deduplication** is the natural next pattern.
