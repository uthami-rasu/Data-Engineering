# Running Total (Cumulative Sum)

## Problem Statement

Given a table of daily sales, calculate the cumulative sales amount up to each day.

### Input

**sales**

| sale_date  | amount |
| ---------- | -----: |
| 2024-01-01 |    100 |
| 2024-01-02 |    200 |
| 2024-01-03 |    150 |
| 2024-01-04 |    300 |

### Expected Output

| sale_date  | amount | running_total |
| ---------- | -----: | ------------: |
| 2024-01-01 |    100 |           100 |
| 2024-01-02 |    200 |           300 |
| 2024-01-03 |    150 |           450 |
| 2024-01-04 |    300 |           750 |

---

## Business Use Cases

### Banking

Calculate the account balance after each transaction.

| txn_date | amount | balance |
| -------- | -----: | ------: |
| Jan 1    |  +1000 |    1000 |
| Jan 2    |   -200 |     800 |
| Jan 3    |   +500 |    1300 |

### E-commerce

Track cumulative revenue over time.

### Inventory

Track stock levels after each movement.

---

## SQL Solution

```sql
SELECT
    sale_date,
    amount,
    SUM(amount) OVER (
        ORDER BY sale_date
    ) AS running_total
FROM sales;
```

## Window Frame Behind the Scenes

The database treats:

```sql
SUM(amount) OVER (
    ORDER BY sale_date
)
```

as roughly:

```sql
SUM(amount) OVER (
    ORDER BY sale_date
    ROWS BETWEEN UNBOUNDED PRECEDING
    AND CURRENT ROW
)
```

Meaning:

```text
Current Row
↑
Take all rows from the beginning
to the current row and sum them.
```

## Interview Variations

### Running Total Per Customer

Input:

| customer_id | sale_date | amount |
| ----------- | --------- | -----: |
| 1           | Jan-01    |    100 |
| 1           | Jan-02    |    200 |
| 2           | Jan-01    |    300 |
| 2           | Jan-02    |    100 |

Output:

| customer_id | sale_date | running_total |
| ----------- | --------- | ------------: |
| 1           | Jan-01    |           100 |
| 1           | Jan-02    |           300 |
| 2           | Jan-01    |           300 |
| 2           | Jan-02    |           400 |

Solution:

```sql
SELECT
    customer_id,
    sale_date,
    amount,
    SUM(amount) OVER (
        PARTITION BY customer_id
        ORDER BY sale_date
    ) AS running_total
FROM sales;
```
