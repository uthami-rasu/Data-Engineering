

# 6. Ranking (ROW_NUMBER, RANK, DENSE_RANK)

This is one of the most frequently asked SQL interview topics.

## Why It's Important

Questions like:

- Highest salary
- Top 3 employees
- Rank students
- Leaderboards
- Nth highest salary

all rely on ranking functions.

---

# Three Ranking Functions

| Function     | Duplicate Values | Gap in Rank? |
| ------------ | ---------------- | ------------ |
| ROW_NUMBER() | No               | No           |
| RANK()       | Yes              | Yes          |
| DENSE_RANK() | Yes              | No           |

---

## Example Data

| employee | salary |
| -------- | -----: |
| A        |  10000 |
| B        |   9000 |
| C        |   9000 |
| D        |   8000 |

---

# ROW_NUMBER()

## Problem Statement

Assign a unique sequence number to every row.

### SQL

```sql
SELECT
    employee,
    salary,
    ROW_NUMBER() OVER(
        ORDER BY salary DESC
    ) AS rn
FROM employees;
```

### Output

| employee | salary |  rn |
| -------- | -----: | --: |
| A        |  10000 |   1 |
| B        |   9000 |   2 |
| C        |   9000 |   3 |
| D        |   8000 |   4 |

### Key Point

Even though B and C have the same salary, they get different numbers.

---

# RANK()

## Problem Statement

Assign the same rank to ties.

### SQL

```sql
SELECT
    employee,
    salary,
    RANK() OVER(
        ORDER BY salary DESC
    ) AS rnk
FROM employees;
```

### Output

| employee | salary | rank |
| -------- | -----: | ---: |
| A        |  10000 |    1 |
| B        |   9000 |    2 |
| C        |   9000 |    2 |
| D        |   8000 |    4 |

Notice:

```text
1
2
2
4
```

Rank 3 is skipped.

---

# DENSE_RANK()

## Problem Statement

Assign the same rank to ties, but don't skip ranks.

### SQL

```sql
SELECT
    employee,
    salary,
    DENSE_RANK() OVER(
        ORDER BY salary DESC
    ) AS drnk
FROM employees;
```

### Output

| employee | salary | dense_rank |
| -------- | -----: | ---------: |
| A        |  10000 |          1 |
| B        |   9000 |          2 |
| C        |   9000 |          2 |
| D        |   8000 |          3 |

Notice:

```text
1
2
2
3
```

No gap.

---

# Interview Template 1: Nth Highest Salary

### 2nd Highest Salary

```sql
SELECT salary
FROM (
    SELECT
        salary,
        DENSE_RANK() OVER(
            ORDER BY salary DESC
        ) AS rnk
    FROM employee
) t
WHERE rnk = 2;
```

### Why DENSE_RANK?

Suppose salaries are:

```text
10000
9000
9000
8000
```

Using `RANK()`:

```text
1
2
2
4
```

There is no rank 3.

Using `DENSE_RANK()`:

```text
1
2
2
3
```

Much safer for Nth highest salary problems.

---

# Interview Template 2: Top N Employees

### Top 3 Salaries

```sql
SELECT *
FROM (
    SELECT
        *,
        DENSE_RANK() OVER(
            ORDER BY salary DESC
        ) AS rnk
    FROM employee
) t
WHERE rnk <= 3;
```

---

# Interview Template 3: Rank Within Department

### Input

| dept | emp | salary |
| ---- | --- | -----: |
| IT   | A   |  10000 |
| IT   | B   |   9000 |
| HR   | C   |   8000 |
| HR   | D   |   7000 |

### SQL

```sql
SELECT
    dept,
    emp,
    salary,
    DENSE_RANK() OVER(
        PARTITION BY dept
        ORDER BY salary DESC
    ) AS dept_rank
FROM employee;
```

### Output

| dept | emp | salary | dept_rank |
| ---- | --- | -----: | --------: |
| IT   | A   |  10000 |         1 |
| IT   | B   |   9000 |         2 |
| HR   | C   |   8000 |         1 |
| HR   | D   |   7000 |         2 |

Ranks restart for each department.

---

# Interview Template 4: Latest Record Per User

Input:

| user_id | order_date |
| ------- | ---------- |
| 1       | Jan 01     |
| 1       | Jan 10     |
| 1       | Jan 20     |
| 2       | Jan 05     |

### SQL

```sql
SELECT *
FROM (
    SELECT
        *,
        ROW_NUMBER() OVER(
            PARTITION BY user_id
            ORDER BY order_date DESC
        ) AS rn
    FROM orders
) t
WHERE rn = 1;
```

### Use Cases

- Latest order
- Latest login
- Latest transaction
- Latest status

---

# When to Use Which?

### ROW_NUMBER()

Use when:

```text
Need exactly one row
```

Examples:

- Latest order
- First login
- Deduplication

---

### RANK()

Use when:

```text
Competition ranking
```

Examples:

- Sports leaderboard
- Tournament ranking

---

### DENSE_RANK()

Use when:

```text
Nth highest salary
Top N salaries
```

Most common interview choice.

---

# Quick Cheat Sheet

### Unique Number

```sql
ROW_NUMBER()
```

### Same Rank + Gap

```sql
RANK()
```

### Same Rank + No Gap

```sql
DENSE_RANK()
```
