# Pattern 9: Percentile Analysis

This pattern is used when you want to know **where a row stands relative to all other rows**.

Examples:

* Top 10% customers
* Top 25% employees
* Median salary
* Customer segmentation
* Performance distribution

---

# Concept Overview

Ranking tells you:

```text
1st
2nd
3rd
```

Percentiles tell you:

```text
Top 10%
Top 25%
Top 50%
Bottom 25%
```

---

# Functions

| Function            | Purpose                    |
| ------------------- | -------------------------- |
| `NTILE(n)`          | Divide rows into n buckets |
| `PERCENT_RANK()`    | Percentage rank (0 to 1)   |
| `CUME_DIST()`       | Cumulative distribution    |
| `PERCENTILE_CONT()` | Median / percentile value  |

# Template 1: NTILE()

## Problem Statement

Divide employees into 4 equal groups (quartiles).

### SQL

```sql
SELECT
    emp,
    salary,
    NTILE(4) OVER(
        ORDER BY salary DESC
    ) AS quartile
FROM employees;
```

---

## Output

| emp | salary | quartile |
| --- | -----: | -------: |
| A   |  10000 |        1 |
| B   |   9000 |        1 |
| C   |   8000 |        2 |
| D   |   7000 |        2 |
| E   |   6000 |        3 |
| F   |   5000 |        4 |

---

## Interpretation

```text
Quartile 1 → Top 25%
Quartile 2 → Next 25%
Quartile 3 → Next 25%
Quartile 4 → Bottom 25%
```

---

# Template 2: Top 10% Customers

## SQL

```sql
WITH ranked AS (
    SELECT
        customer_id,
        revenue,
        NTILE(10) OVER(
            ORDER BY revenue DESC
        ) AS decile
    FROM customers
)
SELECT *
FROM ranked
WHERE decile = 1;
```

---

## Use Cases

* VIP customers
* High-value users
* Best-performing products

---

# Template 3: PERCENT_RANK()

## Problem Statement

Find the relative rank percentage.

### SQL

```sql
SELECT
    emp,
    salary,
    PERCENT_RANK() OVER(
        ORDER BY salary
    ) AS pct_rank
FROM employees;
```

---

## Output

| emp | salary | pct_rank |
| --- | -----: | -------: |
| F   |   5000 |     0.00 |
| E   |   6000 |     0.20 |
| D   |   7000 |     0.40 |
| C   |   8000 |     0.60 |
| B   |   9000 |     0.80 |
| A   |  10000 |     1.00 |

---

## Formula

```text
(rank - 1)
/
(total_rows - 1)
```

---

## Interpretation

```text
0.00 → Lowest
1.00 → Highest
0.80 → Better than 80% of rows
```

---

# Template 4: CUME_DIST()

## Problem Statement

Find percentage of rows less than or equal to current row.

### SQL

```sql
SELECT
    emp,
    salary,
    CUME_DIST() OVER(
        ORDER BY salary
    ) AS cume_dist
FROM employees;
```

---

## Output

| emp | salary | cume_dist |
| --- | -----: | --------: |
| F   |   5000 |      0.17 |
| E   |   6000 |      0.33 |
| D   |   7000 |      0.50 |
| C   |   8000 |      0.67 |
| B   |   9000 |      0.83 |
| A   |  10000 |      1.00 |

---

## Interpretation

For salary 7000:

```text
50% of employees
have salary <= 7000
```

---

# Template 5: Median

## Problem Statement

Find median salary.

### SQL (PostgreSQL)

```sql
SELECT
    PERCENTILE_CONT(0.5)
    WITHIN GROUP (
        ORDER BY salary
    ) AS median_salary
FROM employees;
```

---

## Output

```text
7500
```

Because:

```text
5000
6000
7000
8000
9000
10000
```

Median:

```text
(7000 + 8000)/2
=
7500
```

# Template 6: 90th Percentile

## SQL

```sql
SELECT
    PERCENTILE_CONT(0.9)
    WITHIN GROUP (
        ORDER BY salary
    ) AS p90_salary
FROM employees;
```
